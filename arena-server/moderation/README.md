# Word blocklist for gift notes

`en-blocklist.txt` is the English list from
https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words
(file `en`, 403 entries, downloaded for this repo). It is licensed under
Creative Commons Attribution 4.0 (CC BY 4.0): credit the project above when you
redistribute it.

The list is only a floor. It catches the common slurs and profanity in English,
not every hateful phrase, misspelling or other language.
